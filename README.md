# Meus Sites Favoritos

Este projeto foi desenvolvido como parte da **Agenda 12 – Desenvolvimento de Sistemas I**.  
O objetivo é criar uma página HTML para armazenar e acessar meus sites favoritos.

## Conteúdo
- Título da aba: *Meus sites favoritos*
- Título do corpo: *Meus sites favoritos: Guilherme*
- 5 sites escolhidos:
  - Friv
  - Google
  - YouTube
  - Instagram
  - TikTok
- Cada site contém:
  - Nome em destaque (`<h1>`)
  - Imagem representativa (`<img>`)
  - Link para acesso (`<a>`)

  Projeto criado para fins de estudo e prática de HTML.
